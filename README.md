# 다다다 달리기

폰 화면을 두드려 캐릭터를 달리게 하는 단체 게임입니다. 앞의 큰 화면이 경기장이 되고, 참가자는 QR코드로 접속해 자기 폰을 두드립니다. 앱 설치와 로그인이 필요 없습니다.

- 개인전: 모두가 각자 달립니다. 정해진 탭 수를 먼저 채우면 골인입니다.
- 본부 대항전: 본부별 캐릭터가 달립니다. 인원이 달라도 공평하도록 본부의 **1인당 평균 탭 수**로 속도를 계산합니다.
- 1등이 골인하면 15초 뒤 경기가 마감됩니다. 한 판은 최대 90초입니다.

## 화면 주소

| 누가 | 주소 |
|---|---|
| 큰 화면(진행자) | `https://내주소/host` |
| 참가자 폰 | `https://내주소/` (큰 화면의 QR코드를 찍으면 열립니다) |

## 인터넷에 올리기 (Render 무료 서버 기준)

1. github.com 에 가입하고 새 저장소(New repository)를 만듭니다.
2. 저장소 화면에서 "uploading an existing file"을 눌러 이 폴더의 파일을 모두 끌어다 놓고 Commit 합니다. (`node_modules` 폴더는 올리지 않습니다.)
3. render.com 에 GitHub 계정으로 가입합니다.
4. New → Web Service 를 눌러 방금 만든 저장소를 고릅니다.
5. Build Command 에 `npm install`, Start Command 에 `npm start` 를 넣고, Instance Type 은 Free 를 고른 뒤 만듭니다.
6. 몇 분 뒤 `https://이름.onrender.com` 주소가 생깁니다. 뒤에 `/host` 를 붙여 큰 화면을 엽니다.

무료 서버는 15분 동안 아무도 쓰지 않으면 잠들고, 다시 깨어나는 데 1분쯤 걸립니다. 행사 10분 전에 큰 화면을 미리 열어 두세요. 큰 화면이 열려 있는 동안에는 잠들지 않습니다.

## 내 컴퓨터에서 먼저 돌려 보기

Node.js 18 이상이 필요합니다.

```
npm install
npm start
```

브라우저에서 `http://localhost:3000/host` 를 엽니다. 화면 아래 "연습용 참가자 10명 추가"를 누르면 혼자서도 경기를 돌려 볼 수 있습니다. 같은 와이파이에 있는 폰은 큰 화면의 QR코드로 접속할 수 있습니다.

## 바꿀 수 있는 것

`config.json` 파일을 고칩니다.

```json
{
  "teams": ["1본부", "2본부", "3본부", "4본부", "5본부"],
  "hostPin": ""
}
```

- `teams`: 본부 이름입니다. 2개에서 8개까지 넣을 수 있습니다.
- `hostPin`: 값을 넣으면 큰 화면을 열 때 비밀번호를 묻습니다. 참가자가 `/host` 주소로 들어와 경기를 시작해 버리는 일을 막습니다.

달리는 거리(100, 150, 250탭)는 큰 화면에서 경기 시작 전에 고릅니다. 150탭은 30초 안팎입니다.

## 행사 당일 진행 순서

1. 큰 화면을 열고 "전체 화면"을 누릅니다.
2. 참가자가 QR코드를 찍고 이름과 본부를 고릅니다. 큰 화면의 본부 칸에 이름이 뜹니다.
3. "개인전 시작"을 누릅니다. 3, 2, 1 뒤에 출발합니다.
4. 결과 화면에서 "본부 대항전 시작"을 누릅니다.

## 알아 둘 점

- 초당 18탭을 넘는 입력은 서버가 인정하지 않습니다(자동 클릭 방지).
- 폰 화면이 꺼졌다 켜져도 같은 사람으로 다시 연결됩니다.
- 경기 도중에 들어온 사람은 다음 경기부터 참가합니다.
- 서버를 다시 시작하면 참가자 명단과 기록이 지워집니다.
